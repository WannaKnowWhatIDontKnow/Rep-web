# Rep

A minimal focus timer app. Set a goal, run a timed "rep" (1–30 minutes), write a quick retrospective, and track your history by date.

- **Guest users**: data stored in `localStorage`
- **Signed-in users**: data synced to Supabase, with weekly/monthly/yearly statistics unlocked

## How to Start

1. Install dependencies:
   ```
   npm install
   ```

2. Run the app:
   ```
   npm start
   ```

Opens at `http://localhost:3000`.
